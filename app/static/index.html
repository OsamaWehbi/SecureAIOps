      LLM01 · Prompt injection

      Normalised, rule-based firewall (leetspeak, zero-width, base64 views) + LLM intent adjudication. Per-request random boundary tags (“spotlighting”) prevent delimiter breakout.

      LLM02 · Sensitive disclosure

      Output DLP redacts keys, tokens, private keys, card numbers and credentials before anything reaches the analyst.

      LLM06 · Excessive agency

      Agents are read-only. Every state-changing action is marked requires_approval and recorded with the approver in the audit log.

      LLM07 · Prompt leakage

      A per-process canary token is embedded in system prompts; any response containing it is withheld.

      LLM08 · Poisoned retrieval

      Retrieved passages are spotlighted as untrusted data — documents cannot issue instructions to the model.

      API hardening

      Constant-time API-key auth, rate limiting, strict CSP & security headers, bounded inputs, no error leakage, request correlation IDs.
